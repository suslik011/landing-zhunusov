## Почему этот инструмент (Sass + BEM)

Я выбрал связку Sass и методологии BEM, так как она позволяет создавать масштабируемую и легко поддерживаемую архитектуру стилей. Переменные Sass облегчили управление цветовой палитрой и основными параметрами макета из одного места. Благодаря миксинам для медиазапросов адаптивные стили пишутся компактно и наглядно прямо внутри соответствующих блоков. Вложенность (nesting) и BEM-именование полностью исключают конфликты имен классов в HTML. Основное неудобство заключается в необходимости постоянной компиляции кода в итоговый CSS-файл перед публикацией. По сравнению с чистым CSS этот инструмент ускоряет разработку, а по сравнению с Tailwind и Bootstrap оставляет полный контроль над дизайном и структурой кода.

## Использование ИИ
При выполнении лабораторной работы использовался ChatGPT/Gemini для генерации базовой структуры макета, написания SCSS-миксинов адаптивности и решения проблем с настройкой компиляции Sass.
